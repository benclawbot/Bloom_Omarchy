# Contributing to Bloom

Bloom is intentionally small at runtime and opinionated about visual calm.
Contributions are welcome when they preserve both qualities.

## Before opening a pull request

- Run: python3 test/validate.py
- Run: node test/unit/models.test.js
- Test the plugin on an Omarchy Quattro session when changing QML.
- Keep agent data local and explain any new process or file access.
- Add a scene fixture when changing event or wallpaper behavior.

Please include a short screen capture or annotated description for visual
changes when a live Omarchy session is available. Do not submit generated
assets without documenting their source and intended scene.
